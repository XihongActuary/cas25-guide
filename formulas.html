公式速查 · 一页装下 CAS25 的全部公式

按"初始计量 → 后续滚动 → 利润表 → 三大特例 → 再保 → 衔接"排列，每条公式标注出处章节和一道对应例题——考前扫这一页，等于扫完二十章。

负债口径：流出为正、流入为负 每条公式配出处 + 例题 适合考前速览
⚠️ 全站符号约定（读公式前必看）
本站所有公式采用负债口径：现金流出（赔付、维持费用）记正，现金流入（保费）记负。因此"FCF+RA < 0"意味着净流入（厚利合同），符号方向与其他教材（资产口径）可能相反——以语义判断为准，不要死记符号。

🧱一、初始计量（第06–09章）

保险合同负债构成（BBA 初始） · 第01/09章 保险合同负债 = 履约现金流量（FCF） + 合同服务边际（CSM） 履约现金流量的展开 · 第06章 FCF = Σ [ E(CFₜ) ÷ (1+i)ᵗ ] + RA （未来现金流量概率加权现值 + 非金融风险调整） 首日判断（零下限）· 第09章 FCF₀ + RA₀ < 0 → CSM₀ = −(FCF₀ + RA₀)（厚利，利得递延） FCF₀ + RA₀ ≥ 0 → CSM₀ = 0，亏损 = FCF₀ + RA₀ 立即进损益

对应例题：例21（情形1 CSM=591 / 情形2 亏损499）

获取现金流（IACF）初始处理 · 第04章 IACF ≤ 预期从相关合同收回的现金流 → 确认"获取现金流资产" IACF > 可收回部分 → 差额当期费用化

对应例题：例19（40,000 元佣金三年之旅）

🔄二、后续计量：CSM 滚动与摊销（第09–10章）

CSM 期初→期末滚动（五大调整）· 第09–10章 CSM期末 = CSM期初 + 计息 + 估计变更与模型差异调整 + 亏损转回(负) − 当期摊销 计息 = CSM期初 × 初始锁定利率 i₀ 当期摊销（按责任单元）· 第09章 当期摊销 = (CSM期初 + 计息 + 当期调整) × [ 当期责任单元 ÷ 剩余责任单元总数 ]

对应例题：例26（CSM 591 → 413 → 124 → 0）、例27（万能险 404 → 400 → 458 → 0）

未到期责任负债期末余额 · 第10章 负债期末 = 负债期初 + 当期FCF估计变更 + RA重估 + CSM调整净额 + 金融变动额(计息+折现率变动) − 当期履约现金流实际发生(赔付流出) + 已到期转入已发生赔款负债

对应例题：例26/27 的三年滚动表（表12–16、表17–26）

📈三、利润表三线（第11–12章）

保险服务收入（组成法）· 第11章 当期收入 = 预计当期履约费用 + RA当期释放 + CSM当期摊销 ± 经验调整分担额 ± IACF摊销 （总额原则：合同总对价 − 投资成分，按服务进度分配到各期）

对应例题：例26（647/719/603）、例28（甲3,500 vs 乙4,000）

保险服务费用 · 第11章 当期费用 = 当期赔付及费用(不含投资成分) − 投资成分划转 + RA当期释放 + 亏损部分当期变动 承保损益 = 保险服务收入 − 保险服务费用
保险合同金融变动额及其分解 · 第12章 金融变动额 = 货币时间价值及金融风险调整变动 + 金融假设变更影响 金融变动额 = 计入损益(保险财务损益) + 计入OCI（若选择分解政策） 硬约束①：整个责任期内计入 OCI 的累计金额为零　硬约束②：方法前后一致

✂️四、金融变动额分解三法（第12章）

法一：实际分摊率法 · 第12章 r 满足：剩余现金流按 r 折现的现值 = 当前负债 − 已计入OCI的累计变动 计入损益的利率 = r（如 10% → 7.48%），市场利率即时变动进 OCI

对应例题：例23（r=7.48%，损益 284/234/251，OCI 累计 149/79/0）

法二：预期结算利率法 · 第12章 计入损益的利率 = 初始预期结算利率 × 调整因子 K K 使：初始预计应付金额按初始利率与按 K 调整后利率折现的现值相等（如 K = 1.01854）

对应例题：例24（K=1.01854，损益 284/312/169）

法三：当期账面收益率法（VFA 专用）· 第12/13章 计入损益的金额 = 基础项目当期账面收益率 × 期初负债（不含金融变动部分）

对应例题：例25（资产损益=负债损益 300/330/363，天然对冲）

🧮五、VFA 浮动收费法（第13章）

VFA 判断三条件 · 第13章 ① 条款明确指向清晰可辨认的基础项目　② 企业预计支付持有人相当大部分回报 ③ 应付金额变动的大部分随基础项目价值变动而变动
浮动收费与 CSM 吸收 · 第13章 浮动收费 = 基础项目公允价值 − 预计应付持有人金额（现值口径，如例30：5,862 = 5,000 + 450/1.05 + 478/1.05²） CSM 调整额 = 企业份额当期变动 × ( 期初 CSM ÷ 期初企业份额 ) 企业份额 = 1 − 持有人份额（如例29：基础项目+500、持有人70%→企业150）

对应例题：例29（衍生工具对冲两情形）、例30（投连险 5,862）

📉六、亏损部分（第15章）

亏损部分的确认与摊回 · 第15章 初始亏损 = FCF₀ + RA₀ （>0 时），借记"亏损保险合同损益" 当期冲抵收入 = 亏损部分 × [ 当期责任单元 ÷ 剩余责任单元 ]（贷记保险服务费用） 后续好转：先用有利变动抵销未摊回亏损部分 → 抵尽后重建 CSM → 再有剩余才进损益

对应例题：例A（亏损280 两年摊回）、例B（抵销→重建CSM 60）

⚡七、PAA 保费分摊法（第16章）

PAA 简化与底线 · 第16章 期末负债 = 未到期部分对应的保费（近似按时间进度/风险进度分摊） 当期收入 ≈ 当期到期的保费（可作简化：收入 = 已赚保费口径） 亏损测试不能省：负债 > 相关 IACF 资产 → 超出部分确认亏损并调增负债

对应例题：例C（一年期家财险600）、例D（亏损测试）

🪞八、再保险（第17章）

分保摊回资产初始计量（镜像原则）· 第17章 分保摊回未到期责任资产 = 摊回未来现金流量现值 − 摊回非金融风险调整 + 摊回CSM （与签发人负债方向镜像：例E 中 40% 成数分保 → 资产 247.2 = 435.6 + 48 − 236.4） 分保净成本追溯 · 第17章 净流出 → 比照 IACF 摊销　净流入 → 直接调整 CSM 亏损摊回 = 直接业务亏损 × 预计摊回比例（借分保资产，贷摊回保险服务费用）

对应例题：例E（成数分保镜像例26）

🚉九、新旧衔接（第20章）

过渡日 CSM（公允价值法）· 第20章 CSM过渡日 = 剩余对价 − RA过渡日 − FCF过渡日 结果为负 → 确认亏损（CSM=0）；不追溯调整对比信息 三法选择 · 第20章 全面追溯（重述对比期） / 修正追溯（调整期初权益） / 公允价值法（重新起算）

对应例题：例H（三法对比：CSM 40 / 25 / 亏损−170）

🎲十、RA 三种估计技术（第08章）

非金融风险调整的估计技术 · 第08章 置信区间法：RA = 现金流量分布置信区间（如75%分位）与期望值之差 条件尾部期望法：RA = 不利情景期望 − 无条件期望 成本资本法：RA = 非金融风险所需资本 × 资本成本率

三法可选其一或组合，结果应定期校准（对应例20：巨灾"30%概率"的情景估计）

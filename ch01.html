📜一、CAS25 是什么，为什么要有它

《企业会计准则第25号——保险合同》（CAS25）规范保险合同的确认、计量和列报，与国际会计准则理事会（IASB）的 IFRS17 全面趋同。财政部 2020 年修订发布，境内上市保险公司自 2023 年起执行。

一句话理解改革的动因：旧准则下"保费收入"既包含保障、又包含储蓄投资，利润确认节奏与业务实质脱节，不同公司、不同市场之间不可比。CAS25 把"保险的归保险、投资的归投资"，让利润表第一次讲清楚了保险公司到底靠什么赚钱。

"本准则要求对保险合同进行分组，并将合同组作为计量单元……保险合同负债的计量应当包含以下组成要素：一是履约现金流量，包括与履行保险合同直接相关的未来现金流量的估计、货币时间价值及金融风险调整、非金融风险调整；二是合同服务边际，即企业因在未来提供保险合同服务而将于未来确认的未赚利润。" ——《应用指南2022》第一章 总体要求

1.1 四大变化：新旧准则一张对比表

维度旧准则CAS25（新准则）变化本质
负债构成 未到期责任准备金 + 未决赔款准备金等，口径由准备金评估惯例主导 履约现金流（未来现金流现值 + 非金融风险调整）+ 合同服务边际 首日利得不再进利润，未赚利润(CSM)随服务释放
收入列报 保费收入（含投资成分） 保险服务收入（扣除投资成分，反映服务对价） 投资成分从收入中剔除，规模保费≠收入
亏损确认 准备金不足时通过计提补足，确认相对滞后 亏损合同立即确认亏损，后续通过"亏损部分"冲抵未来收入 会计亏损立即确认原则
披露 相对原则性 金额、判断、风险三层详细披露要求 可比性与透明度大幅提高
🔑 记忆锚点
四大变化可以压缩成一句："负债拆细、收入挤水、亏损快认、披露加码"。

1.3 三大计量模型：一张表选对模型

走完主线 ①②③ 之后，到了计量环节，合同会被分流到三个模型之一。选模型的顺序是先看特殊性（VFA），再看简化条件（PAA），剩下的走默认（BBA）：

模型全称管哪类合同核心特征对应章
BBA 一般模型（Building Block Approach） 所有保险合同的默认模型 履约现金流四要素逐块计量，首日利得进 CSM 递延 06–12章
VFA 浮动收费法（Variable Fee Approach） 具有直接参与分红特征的合同（清晰可辨认的基础项目+相当大部分回报分享） CSM 吸收基础项目市值变动，企业与客户"共担涨跌" 13章
PAA 保费分摊法（Premium Allocation Approach） 责任期不超过一年（或满足条件选择适用）的合同 近似按保费收入节奏确认，简化处理 16章
⚠️ 常见误区
模型选择不是"挑一个最有利的"，而是由合同特征客观决定：VFA 要在合同开始日逐条检验三条件（详见第13章），PAA 要满足责任期等条件（详见第16章）。不满足就回到 BBA——所以先把 BBA 学扎实，是一切的地基。

1.4 负债公式初见面

保险合同负债（BBA 初始计量） 保险合同负债 = 履约现金流量（FCF） + 合同服务边际（CSM） 其中 FCF = 未来现金流现值（折现） + 非金融风险调整（RA）

注意本站统一采用负债口径：流出为正、流入为负。对签发人（保险公司）而言，保费是流入（记负）、赔付和费用是流出（记正）。这套符号约定贯穿全站所有例题，第06章会专门解释为什么用它。

而 CSM 有一个"零下限"规则：

首日判断（厚利 or 亏损） FCF₀ + RA₀ < 0 → 厚利合同 → CSM₀ = −(FCF₀ + RA₀) > 0 FCF₀ + RA₀ ≥ 0 → 亏损合同 → 首日亏损立即进损益，CSM₀ = 0

首日亏损立即确认、首日利得递延——这个"不对称"是 CAS25 最有性格的设计，第09章会拆解它的逻辑。

📖 例21（指南第六章）：100份三年期合同，两种赔付预期的初始计量

题面：甲公司签发100份责任期为3年的保险合同（构成一个合同组），初始确认后立即收到保费1,800元。市场上反映该现金流量特征的折现率为5%，初始确认时非金融风险调整（RA）为120元。

  • 情形1：预计每年末现金流出400元（三年合计1,200元）；
  • 情形2：预计每年末现金流出800元（三年合计2,400元）。

问：两种情形下，初始确认时分别确认 CSM 还是亏损？金额是多少？

第 1 步 · 先自己判断
情形1收到的保费（1,800）比未来赔付现值大还是小？情形2呢？——先写下你的直觉答案再继续。
第 2 步 · 折现未来现金流（负债口径：流出为正、流入为负）
项目情形1情形2
每年现金流出 × 折现因子合计 400×(0.9524+0.9070+0.8638) = 1,089 800×(0.9524+0.9070+0.8638) = 2,179
保费现金流入（记负）−1,800−1,800
FCF₀（未含 RA）−711+379
第 3 步 · 加上非金融风险调整
情形1：FCF₀ + RA₀ = −711 + 120 = −591；情形2：FCF₀ + RA₀ = 379 + 120 = +499。
第 4 步 · 判断符号，得出结论
判断情形1情形2
FCF₀ + RA₀ 符号−591（净流入）+499（净流出）
合同性质厚利合同亏损合同
CSM₀5910
首日损益0（利得递延进CSM）亏损 499，立即进损益
初始确认时保险合同负债591499
第 5 步 · 对照账务处理（指南原文分录）

情形1（厚利）：借：未到期责任负债——未来现金流量现值 711；贷：未到期责任负债——非金融风险调整 120，未到期责任负债——合同服务边际 591。

情形2（亏损）：借：亏损保险合同损益 499；贷：未到期责任负债 499。

💡 这道题的"原型价值"
全书所有复杂例题——VFA、再保、OCI 分解——追到根上都是这五步：折现 → 加 RA → 判符号 → 定 CSM/亏损 → 写分录。做对了这一题，后面的例题只是在这五步上叠加变化。

1CAS25 下保险合同负债由哪两部分构成？
A未到期责任准备金 + 未决赔款准备金
B履约现金流量 + 合同服务边际
C预期保费收入 + 预期赔付支出
D法定准备金 + 偿付能力资本
B 正确。A 是旧准则口径；C 是现金流要素而非负债构成；D 混淆了会计计量与偿付能力监管。
2新准则利润表中，"保费收入"发生了什么变化？
A口径不变，只是科目改名
B全部保费不再确认为收入
C确认为保险服务收入，且剔除投资成分，反映服务对价
D规模保费直接列示为收入
C 正确。CAS25 仅列报与保险服务相关的收入，投资成分不确认为收入——这是"收入挤水"的核心。
3某合同组初始计量：FCF₀ = −200，RA₀ = 50。应确认？
ACSM = 150
B亏损 150 立即进损益
CCSM = 250
DCSM = 200
A 正确。FCF₀+RA₀ = −150 < 0，为厚利合同，CSM₀ = −(−150) = 150。（对照例21情形1的算法。）
4三大模型的适用判断顺序，正确的是？
A先检验是否满足 VFA 三条件，再看 PAA 简化条件，都不满足走 BBA
B自由选择对公司最有利的模型
C所有分红险一律用 VFA
D先看 PAA，因为最简单
A 正确。模型由合同特征客观决定：VFA 是"特殊通道"，PAA 是"简化通道"，BBA 是默认。C 错在间接分红产品恰恰走 BBA（详见第14章）。
5关于 CSM 的"零下限"规则，下列说法正确的是？
ACSM 可以为负，反映预期亏损
BCSM 为负时自动清零，亏损递延到以后期间
CCSM 不得为负，首日亏损立即进损益，但亏损转回后可继续计提 CSM
D亏损合同组的 CSM 等于亏损金额
C 正确。"不得为负 + 损失冲抵后可恢复"是 CSM 的标志性规则（指南总体要求及第六章），首日亏损不进 CSM 而是立即确认——亏损立即确认、利得递延的不对称设计。

📋四、一表小结

要点内容
准则定位规范保险合同的确认、计量、列报，与 IFRS17 趋同，2023 年起执行
四大变化负债拆细（FCF+RA+CSM）、收入挤水（剔除投资成分）、亏损快认（立即确认）、披露加码
主线流程识别 → 分拆合并 → 分组 → 初始计量 → 后续计量 → 列报披露
负债公式保险合同负债 = FCF（现值 + RA）+ CSM；符号口径：流出为正、流入为负
首日判断FCF₀+RA₀ < 0 → 厚利，CSM₀ = −(FCF₀+RA₀)；≥ 0 → 亏损立即进损益，CSM₀ = 0
三大模型BBA（默认）/ VFA（直接参与分红）/ PAA（责任期≤1年简化）
计量单元合同组（组合细分而来），不是单张保单

第20章 · 衔接与过渡

全站收官。新准则生效那天，账上还躺着二十年攒下的旧准备金——它们怎么搬进新世界？CAS25 的衔接规定给了三条路：追溯调整、修正追溯、公允价值法，核心思想是"能用旧数据就用旧数据、不能用就简化"，同时把"重新评估哪些旧判断"的清单划得清清楚楚。这一章决定每家公司首日损益的形状，也是实务工作量最大的一役。

实战篇 · 第 8/8 章 预计用时 25 分钟 对应指南：第十二章衔接规定（本站依据准则归纳）

🎯 开篇三问——读完本章回来作答

  1. 三条过渡方法的差异，本质上是对"哪个时点的信息"和"重述多少历史"的不同选择——怎么用一句话区分？
  2. 过渡日哪些旧判断可以"免检"沿用（不用重新评估）？哪些必须重做？为什么分组偏偏必须重做？
  3. 过渡日 CSM 怎么定？为什么"公允价值法"可能让未来利润表永远少一块（或多一块）？

提示：把过渡想成"旧账换新表"——账还是那些合同，表换了格式和口径；三条路是"重算多细"的档位选择，而不重述比较期间是修正追溯与公允价值法共同的代价与便利。

📜一、过渡日与三条路径

本站依据 CAS25 衔接规定归纳（指南第十二章原文未在精读素材范围内）：过渡日 = 首次执行日，企业自此按新准则列报。存量合同进入新世界有三条路（可按合同组合分别选择）：

方法做法比较期间信息需求
① 追溯调整法视同准则自始存在，用历史实际信息逐期重算重述全部比较期间最高（需要逐合同历史数据，多数保险公司做不到）
② 修正追溯法用过渡日可获得的信息按新规则重算，如同存量合同"在过渡日才签发"不重述（首日调整进期初留存收益）中（过渡日单点数据即可）
③ 公允价值法以过渡日履约现金流量为起点，整体拆借：FCF 可直接用过渡日市场假设估计，无需剥离历史假设；CSM = 过渡日保费对应的公允价值 − RA − 履约现金流量不重述最低（可借助过渡日市场数据与简化）
🔑 三条路的经济学含义
追溯调整 = "把历史拍成连续剧重放"（最忠实、最不可行）；修正追溯 = "从过渡日重看一遍"（默认主力）；公允价值法 = "以市场价切一刀"（数据最省，但把历史经验整体封存：若过渡日估计偏保守，未来将"多赚"一块首日差——这块差不是经营挣的，是切换送利，且永远无法与真实经验对账）。三法都要求把调整计入期初留存收益（不进当期损益）。

1.1 哪些旧判断可以"免检"

为控制成本，准则明确过渡日无需重新评估（除非信息不可得或合同条款有变）：

  • 哪些合同是保险合同（含重大保险风险测试）；
  • 合同的合并与分拆（嵌入衍生工具、投资成分等拆分判断）；
  • 边界相关的判断（如是否构成实质义务）沿用原结论。

必须重做的：

  • 合同分组——按过渡日的剩余责任期与盈利性重新分层（新准则的分组规则与旧准则完全不同，且亏损合同组要单独成组）；
  • 计量本身——FCF、RA、折现率、CSM 全部按新规则在过渡日建立；VFA 认定在特定条件下可沿用原有分红机制判断的合理部分。

1.2 过渡日 CSM 的确定（修正追溯示意）

过渡日 CSM = 保费与相关流量对价（过渡日口径）− RA − 履约现金流量（过渡日估计，用过渡日折现率折现）
若结果 < 0 → 亏损部分计入过渡日留存收益（第15章机制）

注意"折现率用过渡日的"——旧世界的历史利率不进新账。这一点与第07章"首日锁定"的衔接：过渡日就是存量合同的"新首日"。

1.3 其他过渡要点

  • PAA：过渡日符合 PAA 条件的合同组可直接用简化路径（已赚取/未赚取口径切换）；
  • 分出再保：分保摊回资产同样按三法之一过渡，与直接业务的方法选择相互独立（但需披露）；
  • 比较期间：选择修正追溯/公允价值法的，不重述——首份年报将出现"新旧两套口径并列"（本期新准则、比较期旧准则），过渡披露必须说清方法选择、期初调整构成与影响；
  • 首份年报后：OCI 分解政策、中期政策等从过渡日起按新准则确定，不再改。

✏️二、例题精解

📖 例H（本站演算）：一份存量合同的三法对比

背景（本站依据准则方法编制）：某五年期存量保障型合同组，过渡日剩余责任期 3 年。旧账：未到期责任准备金 1,200。过渡日新口径估计：剩余履约现金流量现值 1,050、RA 90；若在过渡日"重新签发"，客户对价（保费等流入现值）为 1,180。历史信息：若完整追溯（视同自始按新准则），首日 CSM 应为 150，此前已按旧准则确认利润 320。

第 1 步 · 修正追溯法
过渡日 CSM = 1,180 − 1,050 − 90 = 40；负债 = 1,050 + 90 + 40 = 1,180。
期初留存收益调整 = 1,200（旧准备金）− 1,180（新负债）= +20（旧账多提 20，释放进权益）。此后三年按新规则滚动（第10章）。
第 2 步 · 公允价值法
无需剥离"如果当年按新准则"的历史——直接用过渡日数据：负债公允价值口径 1,180 同上；差别在 CSM 确定可采用更简化的公允价值切分（如以过渡日同类新合同的 CSM 比例估计）。设结果 CSM' = 25，则留存收益调整 = 1,200 − (1,050+90+25) = +35。
第 3 步 · 追溯调整法（对照）
需重述：首日 CSM 150 − 已确认利润 320 = 过渡日应有的 CSM −170？——负数意味着按新准则此组已亏损 170，应确认亏损部分、CSM 归零：负债 = 1,050 + 90 + 0 = 1,140，且历史比较期间全部重列。结论：三法给出三个不同的期初权益与未来利润轨迹——追溯法（−170 亏损 + 重述历史）最忠实也最痛；这就是"方法选择决定未来利润表形状"的含义。实务中因数据不可得，追溯法极少可完整执行。

🧪三、实战自测

1修正追溯法的核心特征是？
A视同准则自始存在，重述全部比较期间
B以过渡日公允价值为起点，历史经验整体封存
C用过渡日可获得的信息按新规则重算，不重述比较期间，调整进期初留存收益
D继续沿用旧准则直到合同到期
C 正确。A 是追溯调整法；B 是公允价值法；D 不存在（存量合同必须进新世界）。
2过渡日无需重新评估的事项是？
A是否构成保险合同（含重大保险风险）
B合同分组
C履约现金流量的重新估计
D折现率的重新确定
A 正确（除非信息不可得）。分组、FCF、RA、折现率、CSM 都必须在过渡日按新规则建立——"免检"只免判断，不免计量。
3过渡方法选择对首份年报的影响，正确的说法是？
A过渡调整计入当期损益
B调整计入期初留存收益；选修正追溯/公允价值法的会出现新旧口径并列，须做过渡披露
C所有合同组必须用同一方法
D比较期间一律重述
B 正确。方法可按合同组合分别选择；调整进权益不动损益；不重述是比较期并列的根源。
4"公允价值法可能让未来利润表多一块'切换送利'"指的是？
A过渡日确认的收入
B折现率变化带来的 OCI
C比较期间重述产生的差异
D若过渡日估计偏保守，未来经验好于估计时释放的差额——它来自方法切换而非经营
D 正确。公允价值法把历史经验封存在过渡日切分里，日后的经验差异会以"利润"面目出现，分析时须与真实经营区分。
5例H 修正追溯法下，过渡日 CSM 的计算是？
A1,180 − 1,050 − 90 = 40
B1,200 − 1,050 = 150
C1,180 − 1,200 = −20
D150 − 320 = −170
A 正确。对价（过渡日口径）− RA − 履约现金流量 = CSM；B 混入旧准备金；C 是权益调整额；D 是追溯法的口径。
点击选项作答，即时判分

📋四、一表小结

要点内容
过渡日首次执行日；存量合同全部进新准则
三法追溯调整（重述全史）/ 修正追溯（过渡日信息重算、不重述）/ 公允价值法（市场价切分）
调整去向期初留存收益，不当期损益
免检清单是否保险合同、合并分拆、边界判断（信息不可得时除外）
必做清单分组（按过渡日剩余责任期与盈利性）、全套计量、CSM/亏损建立
过渡 CSM对价 − RA − 履约现金流量；负数 → 亏损进权益

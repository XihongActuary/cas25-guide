第03章 · 合并与分拆

保险合同往往不是"纯保险"：账户价值、嵌入选择权、附赠服务都可能藏在一张保单里。本章回答三个问题：哪些合同要合起来算？哪些成分要剥出去算？剥不出去的怎么办？

入门篇 · 第 3/5 章 预计用时 30 分钟 对应指南：第四章（二）合并 ·（三）分拆

🎯 开篇三问——读完本章回来作答

  1. 判断"可明确区分的投资成分"要过哪两道关？"高度关联"有哪两种具体表现？
  2. 嵌入衍生工具在什么条件下必须从保险合同中分拆？分拆顺序为什么是"先衍生工具、再投资成分、最后服务承诺"？
  3. 一张含账户价值 + 死亡给付的寿险保单（指南例14），账户价值为什么不能分拆？

提示：分拆的本质是"把不属于保险的部分交给别的准则"，分拆结果直接决定进入 CAS25 计量的现金流量范围（第06章合同边界的起点）。

📜一、合并：什么时候"几份合同算一份"

"与相同或相关联的合同对方订立的一个保险合同集合或一系列保险合同，可能实现或旨在实现某一整体商业目的，企业应当将这些保险合同合并为一个整体进行会计处理，以反映此类合同的商业实质。" ——《应用指南2022》第四章（二）保险合同的合并

两种典型情形要合并：

  • 完全抵销：一项合同的权利义务与同一时间、同一对方订立的另一合同完全抵销——合并结果不存在任何权利义务；
  • 互为前提：两项合同的权利义务互为前提、互相依赖——合并反映整体商业实质。
⚠️ 常见误区
保单持有人同时购买多份保单或加保以获得价格折扣，不足以表明合同旨在实现某一整体商业目的——不能据此合并。合并看的是权利义务的实质依赖，不是购买行为本身。

二、分拆：三步剥离，剩下的进 CAS25

实务中保险合同可能是"混装"的：保险保障 + 储蓄投资 + 服务承诺 + 嵌入选择权。分拆按固定顺序进行：

3.1 第①步：嵌入衍生工具

典型如退保选择权。依据 CAS22，同时符合三个条件才分拆：①经济特征和风险与主合同不紧密相关；②与嵌入衍生工具相同条款的单独工具符合衍生工具定义；③混合合同不以 FVTPL 计量。分拆出的衍生工具适用金融工具准则——但"嵌入衍生工具本身是保险合同且适用本准则"的除外（如保险合同内的年金转换选择权实质是保险责任的，不拆）。

3.2 第②步：投资成分——本章的重头戏

"投资成分，是指无论保险事项是否发生，企业均须根据保险合同要求偿还给保单持有人的金额。" ——《应用指南2022》第四章（三）2

投资成分的定义很宽（凡"无论如何都要还"的金额都是），但可分拆的只有"可明确区分"的。判断要过两道关：

条件具体表现
第一关：非高度关联① 两者不可单独计量（一个成分的价值随另一个变动而变动）
② 持有人无法单独获益，只能两者同时存在时获益（一个失效/到期导致另一个也失效/到期）
第二关：可单独出售签发企业或其他方能在相同市场或地区单独出售与投资成分条款相同的合同（无须全面排查市场，考虑合理可得信息即可）
🔑 高度关联是"一票否决"
两关是"与"的关系：任何一关不过，投资成分都不可明确区分，就不能分拆，只能留在保险成分里随 FCF 一起计量。判断"不可单独获益"时，看的是合同条款的生死联动——死亡给付 = 账户价值 + 6,000 元、退保给付 = 账户价值，两者同生共死，账户价值高度关联（指南例14）。

3.3 第③步：商品或非保险合同服务承诺

分拆完衍生工具和投资成分后，再看有没有"可明确区分的商品或非保险合同服务承诺"——标准是保单持有人能单独使用或与其他易于获得的资源一起使用而受益。两个"不可明确区分"条件：现金流量及风险与保险成分高度关联；企业提供重大整合服务。

注意：为履行合同必须实施的活动本身不是服务承诺——理赔活动、资产管理活动是企业履约的手段，没有向持有人额外转让商品或服务，不拆（指南例16）。只有单独收费、市场可独立购买的服务（如例17 的理赔外包服务）才拆出去适用 CAS14。

3.4 剩余保险成分：原则上"整体处理、不再细拆"

剩余部分（含未拆的嵌入衍生工具、不可明确区分的投资成分、不可明确区分的服务承诺）作为一个整体适用本准则。两个例外方向：

  • 该拆不拆：仅简化手续拼装的多项保险成分且定价是各自简单相加 → 不作为整体，应拆为多项保险合同（指南例18：银行团体合同中借款人各自选择购买、单独定价 → 每个借款人一份保险合同）；
  • 主险 + 附加险：按"能否分开销售定价、是否同时失效、风险是否相互依赖"三因素判断是否分拆。
💡 合并与分拆的"互斥校验"
合并规定与分拆规定运用后应得出相同判断结果：判断应分拆的成分，不应再通过合并"拆了又合"，反之亦然——两条规则是同一商业实质的两个视角。

3.5 分拆之后：现金流量怎么分

初始确认时，合同现金流量先扣除已分拆嵌入衍生工具和可明确区分投资成分的流量，再按 CAS14 在保险成分与服务承诺之间分摊流入；与各成分直接相关的流出归各成分，不直接相关的流出按"系统合理、反映该成分为单独合同时的预计流出"分摊。分摊至保险成分的现金流量，就是第06章 FCF 计量的起点。

✏️三、例题精解：账户价值分拆吗？理赔服务分拆吗？

📖 例14（指南第四章）：含账户价值的寿险合同——投资成分不可明确区分

题面：甲公司签发含账户价值的人寿保险合同，签发时收到保费 1,200 元。账户价值随持有人自愿缴费而增加、随特定资产投资回报变动、因扣费而减少。条款约定：身故给付 = 账户价值 + 6,000 元；退保给付 = 账户价值。市场上另有金融机构在销售条款相同但不含保险保障的投资产品。该合同已通过重大保险风险测试。

第 1 步 · 先自己判断
市场上能单独买到同条款投资产品——"可单独出售"这一关过了吗？能分拆吗？
第 2 步 · 第一关：高度关联测试
死亡给付和退保给付都以账户价值为基数；保险保障服务与账户价值同时存在、同时失效或满期——一个成分失效会导致另一个失效 → 持有人无法单独获益 → 高度关联成立。
第 3 步 · 结论
虽然"可单独出售"这一关通过（市场上有同条款投资产品），但高度关联一票否决：账户价值不构成可明确区分的投资成分，不从保险合同中分拆，整体适用 CAS25。
第 4 步 · 顺带的观察
账户价值留在保险成分内意味着：它的变动将进入履约现金流量、进而影响 CSM 滚动——这正是第14章"间接分红产品"（BBA + 相机抉择分解）要处理的世界。而如果它被分拆，这张保单将一分为二，一半走 CAS25、一半走金融工具准则。
📖 例17（指南第四章）：单独收费的理赔服务——可明确区分的服务承诺

题面：甲保险公司与乙公司签订保险合同：起赔点 250 万元，超起赔点 100% 保障。同时无论赔付是否超过起赔点，甲公司单独收费为乙公司雇员处理医疗赔付（理赔外包），收费与市场价格一致，市场上有企业单独提供同类外包服务。

第 1 步 · 受益独立性
若甲公司不提供理赔服务，乙公司需自行处理或另雇供应商 → 乙公司从该服务中获得的利益独立于保险保障服务。
第 2 步 · 关联度与整合
理赔服务现金流量与保险保障现金流量不是高度关联（无论是否出险都要提供、都单独收费），且甲公司未提供重大整合服务。
第 3 步 · 结论
理赔服务是可明确区分的服务，应当分拆并适用《企业会计准则第14号——收入》。对照例16：合同内生的理赔活动不拆、单独收费的理赔服务要拆——分水岭是"是否向持有人转让了额外的、可单独受益的服务"。

🧪四、实战自测

1投资成分的定义是？
A合同中与投资账户对应的资产
B无论保险事项是否发生，企业均须偿还给保单持有人的金额
C嵌入衍生工具中与金融风险相关的部分
D保费中超过风险保费的部分
B 正确（指南第四章（三）2 原文）。注意"定义"与"可分拆"是两个层次：所有"无论如何都要还"的金额都是投资成分，但只有可明确区分的才分拆。
2例14 中，账户价值未能分拆的关键原因是？
A市场上没有同条款投资产品
B公司不愿意分拆
C保险保障与账户价值同生共死、高度关联，持有人无法单独获益
D账户价值金额不重大
C 正确。高度关联（无法单独获益/不可单独计量）是一票否决项，与可单独出售的结论无关。
3分拆的正确顺序是？
A嵌入衍生工具 → 可明确区分的投资成分 → 可明确区分的商品或非保险服务承诺
B投资成分 → 嵌入衍生工具 → 服务承诺
C同时进行，不分先后
D服务承诺 → 投资成分 → 衍生工具
A 正确（指南第四章（三）3：先分拆嵌入衍生工具和可明确区分的投资成分后，再考虑分拆服务承诺）。
4下列哪项活动通常不从保险合同中分拆？
A单独收费、市场有同类供给的理赔外包服务
B合同内生的理赔处理活动
C满足 CAS22 分拆条件的嵌入衍生工具
D可单独出售且非高度关联的投资成分
B 正确。为履约必须实施的活动未向持有人转让额外商品或服务，不构成可分拆的承诺（指南例16）。A 对应例17，应拆。
5关于合并与分拆的关系，正确的是？
A先分拆后可以再合并，两者独立运用
B合并优先于分拆
C两套规定的运用应得出相同的判断结果，不应"拆了又合"或"合了又拆"
D分拆优先于合并
C 正确（指南第四章（三）4 末段）。两者是同一商业实质的不同视角，结果必须自洽。

📋五、一表小结

要点内容
合并同对方 + 整体商业目的：完全抵销 / 互为前提；多单折扣≠合并
分拆顺序嵌入衍生工具（CAS22 三条件）→ 可明确区分投资成分 → 可明确区分商品/服务承诺（CAS14）
投资成分两关非高度关联（不可单独计量 / 无法单独获益）＋ 可单独出售；高度关联一票否决
服务承诺持有人能单独或与其他易得资源共同受益才拆；履约必经活动（理赔、资管）不拆
剩余部分整体适用 CAS25（含未拆衍生工具、不可区分投资成分/服务）；拼装式多成分除外（例18）；主附险三因素
流量分摊扣除已拆成分流量后，按 CAS14 分摊流入，直接/系统合理分摊流出 → 进入 FCF

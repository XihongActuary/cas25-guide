第12章 · OCI 与保险合同金融变动额

进阶篇收官章。负债随市场利率起舞，损益表要不要跟着跳？CAS25 给了一个精妙的分流阀：保险合同金融变动额——货币时间价值及金融风险的影响，可以全额进损益，也可以拆成"进损益的"和"进 OCI 的"。拆分的方法就是本章三道官方例题：实际分摊率法、预期结算利率法、当期账面收益率法。

进阶篇 · 第 7/7 章 预计用时 30 分钟 对应指南：第六章（二）4

🎯 开篇三问——读完本章回来作答

  1. 保险合同金融变动额包括哪些变动？通胀假设有时算金融风险、有时不算——分界线在哪？
  2. "分解计入损益和 OCI"的两条硬约束是什么？（提示：一条关于期间总额，一条关于方法匹配）
  3. 例23 中市场利率从 10% 跌到 5%，为什么甲公司第 2 年计入损益的利率却从 10% 变成 7.48%——而不是直接改成 5%？

提示：OCI 是"缓冲垫"不是"垃圾桶"——计入 OCI 的金额必须在合同组期限内全额回吐（累计归零），拆分方法要确保"拉直"之后损益总额等于金融变动额总额。

📜一、什么是保险合同金融变动额

"企业应当将货币时间价值及金融风险的影响导致的未到期责任负债和已发生赔款负债账面价值变动额，作为保险合同金融变动额。" ——《应用指南2022》第六章（二）4

拆开看，它对应滚动表里三处"金融味道"的变动：

  • 货币时间价值：负债的计息（折现的转回）——例26 里每年 84 / 58 / 27 的"承保财务损益"；
  • 金融风险及其变动：市场利率变动导致的未来现金流量现值变化（例23 中第1年末现值从 2,839 跳到 3,272，其中含估计变更的金融影响）；
  • RA 的金融部分（企业选择区分时）：货币时间价值及金融风险影响导致的 RA 变动额，也作为金融变动额处理。
💡 通胀假设的"身份判定"
指南给了明确分界：基于价格指数或基于与资产收益、通胀率挂钩的资产价格的通胀假设 → 与金融风险有关，进金融变动额；基于企业预期的特定价格变化（如本公司医疗服务价格走势判断）→ 与金融风险无关，走现金流估计变更。同一个"通胀"字，身份完全不同。另外，基础项目价值变动（新增和领取除外）导致的合同组计量变动，属于货币时间价值及金融风险的影响——这句话是第13章 VFA 的桥梁。

1.1 会计政策选择：全额损益 vs 分解

方案做法适合谁
全额计入当期损益金融变动额 = 保险财务损益负债不随资产回报变动、或资产多按摊余成本/公允价值计量（如例26）
分解计入系统合理方法确定各期进损益的金额，差额进 OCI选择在合同组合层面作出，须考虑持有的相关资产及其会计处理

两条硬约束（指南原文）：

  • 总额归零：合同组期限内计入 OCI 的金融变动额总额为零——进损益的各期合计必须等于金融变动额总额。OCI 只是时间差，不是豁免；
  • 方法一致：若 RA 的金融部分也分解，其分解方法必须与未来现金流量变动额的分解方法一致；且分解"无须考虑不影响合同现金流量的因素"——资产回报不影响合同现金流量的，就不该把它纳入分解基准。

1.2 非直接参与分红合同：怎么选拆分方法

情形方法要点
金融假设变更对支付金额不具有重大影响 初始确认时确定的折现率（不随基础项目回报变动） 最简单：每期损益 = 负债 × 锁定利率，剩余进 OCI
金融假设变更对支付金额具有重大影响（如结算利率随资产回报浮动的合同） 实际分摊率法 内含利率 r，每期末更新，把更新后的金融变动额总额在剩余期限内系统分摊（例23）
预期结算利率法 基于当期结算利息与未来预期结算利息分摊（例24），适用于用结算利率定应付金额的合同

1.3 直接参与分红合同（VFA）：当期账面收益率法

企业持有基础项目的，必须用当期账面收益率法：计入当期保险财务损益的金额 = 基础项目按相关会计准则计入当期损益的金额，两者相抵后净额为零——让资产端和负债端在损益表上"同频共振"，天然消除会计错配（例25）。不持有基础项目的（或某些期间不持有），退回非 VFA 的两法之一；持有状态切换时，变更前计入 OCI 的累计金额视同沿用原方法在以后期间回吐，不得重述比较信息、不得重算。

🔑 三法的共同灵魂
实际分摊率法的 r、预期结算利率法的调整因子 K、当期账面收益率法的资产损益——三者都在干同一件事：给"进损益"挑一个平滑且最终闭合的基准。利率跌了，不是立刻按新利率确认损益（那会让损益表随市场大起大落），而是解一个"余下期间拉直"的方程，让 OCI 当缓冲、损益走平滑路径、合同到期时缓冲清零。

✏️二、例题精解：三法对决

例23、例24 同一底稿（100 份三年期合同、趸缴 3,000 元、第1年末市场利率 10%→5%），只换利益分配政策与拆分方法；例25 换成 VFA 合同。三例对照着读，方法差异一目了然。

📖 例23（指南第六章）：实际分摊率法——r 从 10% 更新为 7.48%

背景：保费 3,000 元投资 2 年期 10% 固息债券（到期再投 1 年期）；利益分配政策为责任期末投资资产余额的 94.64% 付给保单持有人。初始：预期资产 3,993（3,000×1.1³）、应付 3,779、现值 2,839（3,779/1.1³）。第1年末市场利率降至 5%：资产再投资预期降为 3,812（3,000×1.1²×1.05）、应付 3,608、现值 3,272（3,608/1.05²）。

第 1 步 · 为什么 r ≠ 5%
金融变动额总额 = 3,608 − 2,839 = 769。约束：各期计入损益之和 = 769，且第1年已按 10% 计了 284（2,839×10%）。若第2、3年直接按 5%，合计将小于 769，OCI 无法归零。于是解方程（第1年末更新 r）：
2,839×10% + 2,839×1.10×r + 2,839×1.10×(1+r)×r = 769
解得 r = 7.48%
r 是"拉直"后的等效利率：比旧 10% 低（利率确实跌了）、比新 5% 高（要补回第1年多计的部分）。

第 3 步 · 读表要点
第1年金融变动额 433 中，损益只认 284，多出来的 149 是市场利率下跌导致的现值上升，进 OCI"暂存"；第2、3年每期损益（234 / 251）都大于当期金融变动额（164 / 172），差额就是在回吐 OCI。损益表看到的是一条平滑的"10% → 7.48%"路径，市场冲击被全部吸收在 OCI。
📖 例24（指南第六章）：预期结算利率法——调整因子 K = 1.01854

背景：沿用例23，利益分配政策改为"结算利率 = 投资收益率 − 2 个百分点"（初始 10% 投资收益率 → 8% 结算利率），账户价值 3,000 → 3,240 → 3,499 → 3,779，现值仍 2,839。第1年末利率下跌：第3年结算利率预计改为 3%（5%−2%），第3年末账户价值调整为 3,604（3,000×1.08²×1.03），金融变动额总额 = 3,604 − 2,839 = 765。

第 1 步 · 解出调整因子 K
拆分基准从"资产内含利率"换成"结算利率"：设调整后结算利率 = (1+8%)×K − 1，K 满足总额闭合：
2,839×[(1.08)K−1] + 2,839×[(1.08)K]×[(1.08)K−1] + 2,839×[(1.08)K]²×[(1.03)K−1] = 765
解得 K = 1.01854；第1、2年调整后结算利率 = 10.002%，第3年 = 4.910%
直觉：8% 的结算利率"不够分"765 的金融变动额（每年才 8% 出头），K 把各年利率整体乘大一点，拉到能闭合为止。

第 3 步 · 两法对比
底稿相同（市场利率同样 10%→5%），实际分摊率法解"内含利率 r"、预期结算利率法解"结算利率调整因子 K"；r 直接作用于负债现值，K 作用于合同约定的结算利率。选择依据是指南那句"对于使用结算利率确定应付保单持有人金额的合同，采用预期结算利率法"——合同现金流怎么定，拆分基准就跟着怎么走。
📖 例25（指南第六章）：VFA + 当期账面收益率法——损益 300 / 330 / 363

背景：100 份 VFA 合同，保费 3,000 元投资 3 年期到期一次还本付息固息债券（基础项目），分类为FVOCI 金融资产；期满按基础项目公允价值的 95%（扣 5% 资产管理费）支付保单持有人。债券实际利率 10%，各年末公允价值 3,622 / 3,803 / 3,993。

第 2 步 · "相抵为零"怎么读
损益表上：资产端 FVOCI 债券确认利息收入 300（公允价值波动进资产端 OCI），负债端金融变动额 622 中只把 300 计入保险财务损益——两边同额相抵，净零。负债端剩余 322（= 622 − 300，市场利率下行导致的负债增值）进保险合同 OCI，与资产端 OCI（公允价值 − 摊余成本 = 322）也同额相抵。利润表与净资产双重免疫于市场利率波动——这就是"资产用什么节奏、负债就用什么节奏"的错配消除设计。
第 3 步 · 与例23/24 的根本差异
例23/24 的拆分基准是解方程解出来的"等效利率"（r 或 K），例25 的拆分基准直接抄资产端的账——FVOCI 债券计入损益 300/330/363，负债端照单全收。这要求企业确实持有基础项目；不持有（或某期间起不持有）的，退回实际分摊率法或预期结算利率法，且切换时 OCI 累计额不得重算。

🧪三、实战自测

A实赔低于预期的经验调整
B货币时间价值及金融风险的影响导致的未到期责任负债账面价值变动
C赔付频率估计的变更
DCSM 摊销
B 正确。A、C 是非金融估计/经验变动（A 进收入、C 调 CSM），D 是服务对价的释放，都不是金融变动额。
2"分解计入损益和 OCI"政策的选择层面与约束是？
A合同组层面选择；OCI 总额须为零
B合同层面选择；OCI 可留存至处置
C合同组合层面选择；合同组期限内计入 OCI 总额为零，损益合计等于金融变动额总额
D公司整体层面选择；无总额约束
C 正确。指南要求在合同组合层面作出选择、考虑持有的相关资产及其会计处理；分解必须确保期限内 OCI 总额为零——拉直后损益合计与金融变动额总额相等。
3例23 中，第 1 年末市场利率已跌至 5%，第 2 年计入损益的实际分摊率却是 7.48%。7.48% 的含义是？
A使剩余期间损益分摊总额与金融变动额总额闭合（OCI 归零）的内含利率，每期末更新
B新旧利率的简单平均（10%+5%）/2
C债券的到期收益率
D结算利率减 2 个百分点
A 正确。r 由闭合方程解出：2,839×10% + 2,839×1.10×r + 2,839×1.10×(1+r)×r = 769。它兼顾了"利率确实降了"（低于 10%）和"第1年已多计损益需要回补"（高于 5%）。
4例25 中，第 1 年负债端金融变动额 622 元，计入保险财务损益的却是 300 元。300 的确定依据是？
A2,839×10.002% 的等效利率
B初始确认时锁定的折现率
C当期结算利息金额
D持有的基础项目（FVOCI 债券）按会计准则计入当期损益的金额
D 正确。持有基础项目的 VFA 合同必须用当期账面收益率法：负债端计入损益 = 资产端计入损益（300/330/363），相抵净额为零，消除错配。
5企业此前不持有基础项目（用实际分摊率法），后因情况变化开始持有基础项目。已计入 OCI 的累计金额应如何处理？
A重述以前期间比较信息，按当期账面收益率法重算
B视同沿用原方法将累计金额计入以后期间的保险财务损益，不重述、不重算
C一次性转入留存收益
D在 OCI 中永久留存
B 正确。指南明确：变更日基于变更前最近时点假设的 OCI 累计额，视同沿用原方法回吐；不得重述比较信息、不得重新计算、变更后不得再改假设。

📋四、一表小结

要点内容
定义货币时间价值及金融风险的影响导致的未到期责任负债与已发生赔款负债账面价值变动额
通胀判定价格指数/挂钩资产价格 → 金融；企业预期的特定价格变化 → 非金融
政策选择全额进损益，或分解进损益+OCI；合同组合层面选择，考虑资产及其会计处理
硬约束期限内 OCI 总额为零（损益合计 = 金融变动额总额）；RA 金融部分分解方法须与现金流一致
非 VFA 三情形影响不重大 → 锁定折现率；影响重大 → 实际分摊率法（r=7.48%）/ 预期结算利率法（K=1.01854）
VFA持有基础项目 → 当期账面收益率法（损益=资产损益，相抵为零，例25 表11）；不持有 → 退回非 VFA 两法
切换规则持有状态变更：OCI 累计额视同沿用原方法回吐，不重述、不重算

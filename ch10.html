第10章 · 后续计量全景：负债滚动表

全站核心章。初始确认之后，负债像一条河流：计息使其上涨、摊销与释放使其下降、经验与估计变动改变河道。本章用指南例26 的三年完整滚动表，把 CSM 五大调整、经验调整与估计变更的分流、收入的构成，一次性串成闭环。

进阶篇 · 第 5/7 章 预计用时 40 分钟 对应指南：第六章（二）后续计量

🎯 开篇三问——读完本章回来作答

  1. 合同服务边际的"五大调整"是哪五项？哪些履约现金流量变动不能调整 CSM？
  2. 例26 第 2 年：实际赔付 300（预期 400）、第 3 年预期从 400 下调到 280——这两件事分别走什么通道？对当期损益有什么不同影响？
  3. 三年收入 647 / 719 / 603，各自的构成是什么？为什么第 2 年最大？

提示：滚动表只有六类动作——期初余额、年初现金流量、财务损益（计息）、与未来服务相关变动、与当年服务相关变动、年末现金流量。所有复杂业务都能塞进这六行。

📜一、后续计量的两张负债与一张滚动表

"企业应当在资产负债表日通过未到期责任负债与已发生赔款负债对保险合同组进行后续计量。未到期责任负债包括资产负债表日分摊至保险合同组的、与未到期责任有关的履约现金流量和当日该合同组的合同服务边际。" ——《应用指南2022》第六章（二）后续计量

已发生赔款负债（现值 + RA，无 CSM）承接出险后的赔案；未到期责任负债（现值 + RA + CSM）承载尚未到期的责任。本章聚焦后者的滚动。对不具有直接参与分红特征的合同组（BBA），CSM 期末账面价值 = 期初 + 五大调整：

调整内容方向直觉
① 当期归入的新合同当期新归入该组的合同对 CSM 的影响金额新本钱入池
② 计提利息按初始锁定的不随基础项目回报变动的加权平均折现率计息货币时间价值
③ 与未来服务相关的履约现金流量变动按初始锁定折现率计量的保费经验调整、未到期现值估计变更、投资成分/保单贷款的预计-实际差额、与未来服务相关的 RA 变动等河道改向：利好加厚、利空削薄（撞零即亏损）
④ 汇兑差额外币合同组的 CSM 汇兑变动汇率通道
⑤ 当期摊销按责任单元（利益金额或数量 × 责任期）平均分摊，计入保险服务收入蓄水池放水
⚠️ 四类变动不调整 CSM
① 货币时间价值及金融风险及其变动导致的现值变动（走金融变动额通道）；② 企业选择作为金融变动额的 RA 变动；③ 已发生赔款负债的估计变更（那是当期费用的事）；④ 除保费经验调整外的其他经验调整。核心口诀：金融的归金融（损益/OCI），已发生的归当期（费用），未来的才归 CSM。

关键解读 1 · 两件事两种通道
实付 300 < 预期 400：差的 100 是经验调整，与当年服务相关 → 与实付 300 一起体现在收入里；第 3 年预期 400→280：折现 (400−280)/1.05 = 114 是估计变更，与未来服务相关 → 加上 RA 变动 10，合计 调增 CSM 124（分录⑨：借 现值 114、RA 10；贷 CSM 124）。当期损益一分钱不动——利好在未来。
关键解读 2 · 收入为什么不降反升
收入 719 = 400（预计赔付，含经验调整 100 + 实付 300）+ 40（RA 释放）+ 279（CSM 摊销）。CSM 摊销 279 = (413 + 124 + 21) ÷ 2——估计利好先加厚 CSM，再按剩余两年责任单元均摊，所以比第 1 年的 207 还大。
关键解读 3 · 计息的锁定利率
58 = 744×5%（现值）+ 413×5%（CSM）——用的仍是初始 5%，与当年市场利率无关（第07章）。

实际 280 = 修改后预期，无新经验调整；收入 603 = 280 + 30（RA 释放）+ 293（CSM 摊销），其中 293 = 279 + 14（含当年计息的余额全数摊完）。现值 267 + 计息 13 − 支付 280 = 0——三条河道同时归零。
三年总账（验证）
收入合计 1,969 = 赔付 980（400+300+280）+ RA 120 + CSM 本息 649 + 经验调整净额 100 + 估计变更影响？——直接验现金：保费 1,800 − 赔付 980 = 820；损益表：收入 1,969 − 赔付和费用 980 − 承保财务损益 169 = 820 ✓。账是平的：三年利润恰等于现金净流入。
🔑 这张滚动表值得打印贴墙
六行动作（期初/年初现金/计息/未来服务/当年服务/年末现金）可以装载任何 BBA 合同组：万能险的相机调整（第14章）、VFA 的基础项目份额变动（第13章）、亏损部分的确认转回（第15章），都是往"与未来服务相关变动"或"与当年服务相关变动"里填新行而已。

🧪三、实战自测

1下列哪项不调整 CSM？
A已发生赔款负债的估计变更
B与未来服务相关的未到期现值估计变更
C按初始折现率计量的保费经验调整
D当期归入该组的新合同
A 正确。已发生赔案的估计变更属于当期费用范畴，不进 CSM。B、C 是五大调整③的内容，D 是调整①。
2例26 第 2 年实际赔付 300（预期 400），差额 100 的处理是？
A调整 CSM 100
B直接冲减当期费用 100
C与当年服务相关的经验调整，通过保险服务收入体现
D计入其他综合收益
C 正确。赔付经验调整与当年服务相关，随收入确认（收入 719 中含 100）；注意与保费经验调整（与未来服务相关、调 CSM）区分。
3例26 第 2 年末预计第 3 年赔付 400→280，CSM 因此？
A减少 114
B增加 124（现值 114 + RA 10）
C增加 120（名义差额）
D不变
B 正确。(400−280)/1.05 = 114 按 5% 锁定利率折现，加 RA 变动 10，合计调增 CSM 124（分录⑨）。
4例26 三年 CSM 滚动的正确序列是？
A591 → 413 → 155 → 0
B591 → 384 → 279 → 0
C591 → 413 → 296 → 0
D591 → 413 → 279 → 0
D 正确。第1年 591+29−207 = 413；第2年 413+21+124−279 = 279；第3年 279+14−293 = 0。
5CSM 摊销的责任单元，指南要求考虑？
A仅剩余年限
B每项合同所提供的利益金额或数量及预计责任期
C保费金额
D赔付发生的时间分布
B 正确。指南：先识别责任单元（利益金额或数量 × 预计责任期），CSM 平均分摊至每一责任单元。例26 用"各年责任单元相等"，例30 用"当年有效人数"。

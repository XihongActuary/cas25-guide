第09章 · 合同服务边际 CSM（初始确认）

CSM 是 CAS25 最有性格的设计：首日利得递延、首日亏损立即确认。本章聚焦初始确认——三项之和公式、零下限规则、IACF 的角色转换，以及"初始负债等于零"这个反直觉的教学点。后续滚动请看第10章。

进阶篇 · 第 4/7 章 预计用时 25 分钟 对应指南：第六章（一）初始计量

🎯 开篇三问——读完本章回来作答

  1. 初始计量的"三项之和"是哪三项？为什么 IACF 资产的终止确认要算进来？
  2. 厚利合同的初始确认时点上，保险合同负债恰好等于零——为什么一个"将要赚钱"的合同，账面负债是零？
  3. 亏损合同组的初始负债等于什么？CSM 又等于什么？

提示：把 CSM 理解成"负的负债"——它把首日利得压在负债里，让未来收入变厚、而不是首日利润变厚。

📜一、初始计量：三项之和定乾坤

"企业应当在合同组初始确认时计算下列各项之和：（1）履约现金流量；（2）在该日终止确认保险获取现金流量资产以及其他相关资产或负债对应的现金流量；（3）合同组内合同在该日产生的现金流量。上述各项之和反映为现金净流入的，企业应当将其确认为合同服务边际；反映为现金净流出即合同组在初始确认时发生首日亏损的，企业应当将上述各项之和计入当期损益，即亏损保险合同损益，同时，将该亏损部分增加未到期责任负债账面价值。" ——《应用指南2022》第六章（一）初始计量
初始确认判断（本站负债口径：流出为正、流入为负） 三项之和 = FCF₀（含RA） + IACF资产终止确认额 + 当日产生的现金流量 < 0（净流入）→ 厚利合同：CSM₀ = −三项之和，首日利润 = 0 ≥ 0（净流出）→ 亏损合同：首日亏损 = 三项之和进损益，CSM₀ = 0

1.1 为什么 IACF 要参与初始计量

佣金在合同签发前已付、挂在"保险获取现金流量资产"上（第04章）。合同组初始确认时，这份资产终止确认、其金额转入合同组计量——相当于"过去的投入折算进这份生意的本钱"。逻辑：卖保单赚不赚钱，要看全部成本，佣金不能游离在计量之外。这正是第②项的用意。

1.2 亏损合同的初始处理

  • 亏损金额借记亏损保险合同损益（立即进损益）；
  • 同时亏损部分（loss component）增加未到期责任负债账面价值——它像一块"负 CSM"，未来通过冲抵收入转回（第15章专讲）；
  • 此时合同组 CSM = 0，保险合同负债 = 履约现金流量（指南明文）。
🔑 不对称设计的逻辑
首日利得递延（进 CSM）、首日亏损立即确认——这不是会计保守主义拍脑袋，而是控制理论的推论：未来服务还没提供，利得不应提前确认（收益实现有赖于履约）；而亏损反映的是现有义务超额，义务已经站在那里，就该立刻认。会计上叫"不对称"，经济上叫"如实反映"。

1.3 保费的三种时点归宿

情形处理对应指南表述
初始确认时或之前收到/应收直接进 FCF（作为流入，第06章清单①）例21/26：保费 1,800 计入初始计量
责任期内收到（既有合同）与未来服务相关 → 经验调整 + 估计变更，调整 CSM第六章（二）1（3）①：采用初始折现率计量的保费经验调整
未来新合同的保费边界外，不进计量第六章（一）1（2）：不得确认为保险合同负债

第二种是实务重点：期缴保单每期缴费，实际与预期的差额（经验调整）按初始锁定折现率折现后调 CSM；预期未来缴费的变更同样调 CSM。保费从此不再是"收入"，而是负债计量的输入。

✏️二、例题精解

📖 例21 情形1（指南第六章）：初始负债为什么恰好是零

背景：保费 1,800 立即收到，流出现值 1,089，RA 120，折现率 5%。

第 1 步 · 三项之和
FCF₀ 现值 = 1,089 − 1,800 = −711；加 RA 120 → −591；无 IACF 资产、当日无其他现金流量。三项之和 = −591（净流入）。
第 2 步 · 确认 CSM
CSM₀ = 591。初始保险合同负债 = FCF（−711 + 120 = −591）+ CSM 591 = 0。
第 3 步 · 直觉校准
"收了 1,800、欠 1,089 的赔付义务加 120 的风险补偿，净头寸是 +591 的资产"——但会计不让你确认首日资产（那是没挣到的钱），于是放一个 +591 的 CSM 进负债把它压平。负债归零、利润归零、未来收入归 591+：这就是 CSM 的"蓄水池"角色。
第 4 步 · 对照分录（指南原文）
借：未到期责任负债——未来现金流量现值 711
　贷：未到期责任负债——非金融风险调整 120
　　　未到期责任负债——合同服务边际 591
（同一科目的三个明细对转，净额为零；收到保费后再贷记现值 1,800，负债转为 1,089+120+591 = 1,800）
📖 例21 情形2 + IACF 延伸：亏损确认与佣金结转（本站组合演算）

Part A · 情形2（官方）：每年流出 800，流出现值 2,179。三项之和 = 2,179 − 1,800 + 120 = +499（净流出） → 亏损合同。

亏损的账务（指南原文）
借：亏损保险合同损益 499　贷：未到期责任负债 499
初始负债 = 履约现金流量 499（= 2,179 + 120 − 1,800），CSM = 0，亏损部分 499 挂账待冲抵。

Part B · IACF 延伸（本站依指南方法编制）：设签发前已付佣金 100（挂 IACF 资产），其余同情形1。三项之和 = −591 + 100 = −491 → CSM₀ = 491。分录：借：未到期责任负债——现值 711、IACF资产相关处理贷方 100；贷：RA 120、CSM 491（净额仍为零）。佣金把未来利润削掉 100——本钱计量的完整性，就在这 100 里。

💡 与第04章例19 的分工
例19 讲 IACF 的生（发生、分摊、减值），本章讲它的灭（终止确认进组）。一个资产的一生，恰在初始确认时点完成角色转换：从"预付款"变成"利润的减项"。

🧪三、实战自测

1初始确认的"三项之和"不包括？
A履约现金流量（含 RA）
B未来新合同组的预期保费
C终止确认 IACF 资产对应的现金流量
D合同组内合同在初始确认当日的现金流量
B 正确。未来新合同在边界外，不属于任何现有组的初始计量；A、C、D 正是三项之和的构成。
2厚利合同组初始确认时，保险合同负债等于？
A零（FCF 与 CSM 恰好对冲）
B履约现金流量
CCSM
D首日利得
A 正确。负债 = FCF（−591）+ CSM（591）= 0。B 是亏损合同的特征；首日利得永不上表。
3责任期内收到的既有合同期缴保费，应？
A立即确认为保险服务收入
B计入当期损益的其他收益
C按初始锁定折现率计量的经验调整，调整 CSM
D直接增加留存收益
C 正确。与未来服务相关的保费经验调整按初始折现率折现后调 CSM（指南第六章（二）1（3）①）。
4亏损合同组的初始确认，正确的说法是？
A亏损进 CSM，随服务递延确认
B亏损递延到期末确认
C初始负债等于零
D亏损立即进损益，亏损部分增加负债账面价值，CSM 为零
D 正确。A 恰好说反（利得递延、亏损立即）；C 是厚利合同的特征；亏损合同初始负债 = 履约现金流量。
5首日利得递延、首日亏损立即确认的"不对称"，其内在逻辑是？
A为了避免企业操纵利润的制度设计，无经济含义
B利得实现依赖未来履约而应递延；亏损反映现有义务超额应立即如实反映
C与国际准则不一致的中国特色
D仅为简化实务操作
B 正确。CAS25 与 IFRS17 在此完全趋同：控制理论下，未履约的服务带来的是"未挣"的利得；而义务超出现有经济利益的部分，在初始确认时点已是事实。

📋四、一表小结

要点内容
三项之和FCF（含RA）+ 终止确认 IACF 等资产/负债 + 当日产生的现金流量
符号判断净流入 → CSM（首日利润 0）；净流出 → 亏损立即进损益（CSM = 0）
厚利合同初始负债 = 0；收到保费后负债 = 流出现值 + RA + CSM
亏损合同初始负债 = 履约现金流量；亏损部分增加负债、未来冲抵收入
IACF 结转初始确认时终止确认，金额进组计量（削薄 CSM）
保费三时点初始→进 FCF；期内→经验调整调 CSM；未来新单→边界外不计量
